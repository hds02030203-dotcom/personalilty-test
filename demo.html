2. Header 컴포넌트 (Header.js)

로고 및 상단 태그 배지를 포함하는 독립형 헤더 컴포넌트입니다.

3. LandingCard 컴포넌트 (LandingCard.js - 1. 시작화면)

PRD 화면 흐름 [1. 시작화면]의 히어로 컴포넌트입니다. (배지, 타이틀, 3대 특징 카드, CTA 버튼)

4. QuizView 컴포넌트 (QuizView.js - 2. 테스트 진행 화면)

PRD 화면 흐름 [2. 테스트 진행 화면] 전체를 관장하는 모듈형 컴포넌트입니다. (프로그레스 바 + 카드 + 이전 버튼)

5. LoadingView 컴포넌트 (LoadingView.js - 3. 분석 로딩 화면)

PRD 화면 흐름 [3. 분석 로딩 화면] 전체를 관장하는 컴포넌트입니다. (듀얼 스피너 + 실시간 문구 갱신 + 100% 프로그레스 채움)

3. ProgressBar 컴포넌트 (ProgressBar.js)

테스트 질문 진행률을 실시간 업데이트하는 인터랙티브 프로그레스 바입니다.

4. QuestionCard 컴포넌트 (QuestionCard.js)

상황 제시형 문항 카드와 A, B, C, D 4지선다 선택지 버튼입니다.

5. LoadingSpinner 컴포넌트 (LoadingSpinner.js)

듀얼 오비탈 스피너 회전 및 로딩 바 애니메이션 컴포넌트입니다.

6. ResultCard 컴포넌트 (ResultCard.js)

최종 성향 유형별 프로필, 강점/보완점 카드입니다. 아래 버튼으로 6가지 유형을 변경해보세요.

7. SynergyCard 컴포넌트 (SynergyCard.js)

환상의 짝꿍 및 주의가 필요한 짝꿍 카드입니다.

8. ToastNotification 컴포넌트 (ToastNotification.js)

공유 완료 및 시스템 알림을 전달하는 팝업 토스트입니다.
